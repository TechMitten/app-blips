Welcome to AppBlips — the fastest way to turn an idea into a real, working app or website. Describe what you want in plain English, watch it build live, and walk away with a single HTML file or a ZIP of pages you can use anywhere. AppBlips is a free app that runs on your own computer with your own API key: install it on Windows or Linux, or run it from source or with Docker on any system.

## How it works

<Steps>
  <Step title="Describe your idea">
    Type a plain-English description of the app you want to build — no technical jargon required. The more specific you are, the better AppBlips can match your vision.
  </Step>
  <Step title="Watch it build live">
    AppBlips streams the result directly into a live sandboxed preview. You can see every line appear in real time and interact with the app the moment generation finishes.
  </Step>
  <Step title="Export your project">
    Download your app or website as a single HTML file or a ZIP of pages to host or share anywhere.
  </Step>
</Steps>
