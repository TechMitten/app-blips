Here are quick answers to the most common questions about AppBlips — what it can build, how the AI works, and the differences between the hosted and self-hosted options.

<AccordionGroup>
  <Accordion title="What kind of apps can AppBlips build?">
    AppBlips generates single-file HTML apps and multi-page websites. That covers a wide range of practical and creative projects: interactive tools, mini-games, dashboards, habit trackers, forms, quizzes, calculators, data visualizers, portfolio sites, and more.

    AppBlips is not designed for native mobile apps or full-stack web applications with complex backends. Apps it produces are fully self-contained HTML files that run entirely in the browser, and multi-page websites export as self-contained static ZIP archives.
  </Accordion>

  <Accordion title="Do I need to know how to code?">
    No. AppBlips is built for anyone who can describe what they want in plain English. You do not need to know HTML, JavaScript, or React to get useful results. If you do code, you can read, export, and change everything AppBlips generates.

    That said, if you have some coding knowledge, more precise prompts — ones that name specific behaviors, edge cases, or UI patterns — tend to produce better first drafts and reduce the number of follow-up tweaks you need to make.
  </Accordion>

  <Accordion title="What does the license allow?">
    AppBlips is open source under the [MIT License](https://github.com/techmitten/app-blips/blob/master/LICENSE). You can use, modify, and redistribute it, including commercially, as long as you keep the copyright and license notice. The official hosted service is [appblips.com](https://appblips.com). The license text is the authoritative version.
  </Accordion>

  <Accordion title="Which AI models can I use?">
    On appblips.com, the AI is included with your plan and there's nothing to set up.

    In the desktop app or a copy you run yourself, you bring your own key. DeepSeek is built in, and any other service compatible with the OpenAI chat completions API can work too, such as OpenRouter, Ollama, or Groq. Fill in the key and the model in your `.env` file (or set them in Settings → AI in the desktop app):

    ```bash
    OPENAI_API_KEY=your-api-key
    OPENAI_LLM_MODEL=deepseek-v4-pro
    ```

    See [Configuration](/self-hosting/configuration#other-openai-compatible-services) for other services.
  </Accordion>

  <Accordion title="What happens to my API key?">
    In a copy you run yourself, your API key lives only in the `.env` file on your computer (or in your OS keychain for the desktop app). On appblips.com you don't need a key. The key is used exclusively by the AppBlips server when it calls your AI provider — it is never sent to the browser, never embedded in generated app code, and never included in any exported HTML file.
  </Accordion>

  <Accordion title="Can I export the generated project?">
    Yes. Use the **Export** option to download your app as a single self-contained HTML file, or your website as a `.zip` archive of pages. The exported files work in any modern web browser with no server or build step. They load styling and some libraries (such as Tailwind CSS or the Phaser game engine) from public CDNs, so they need an internet connection.
  </Accordion>

  <Accordion title="How do I undo a change?">
    Use the **undo button** in the workspace toolbar to step back one change at a time. You can also open the **History** sidebar to see every version of your app and jump directly to any earlier state.
  </Accordion>

  <Accordion title="Is there a limit on how many apps I can build?">
    In **self-hosted** mode, there is no limit imposed by AppBlips. You are only constrained by your AI provider's rate limits and your own usage budget.

    In the **cloud studio** at start.appblips.com, each plan has a monthly usage allowance rather than a limit on the number of apps. See [Pricing](/pricing) for the plans, the free trial, and what happens when you run out.
  </Accordion>
</AccordionGroup>
