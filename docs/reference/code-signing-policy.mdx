Code signing adds a digital signature to a program, so Windows can tell who made it. The Linux release files on GitHub aren't code-signed. The [Microsoft Store](https://apps.microsoft.com/detail/9nk9ss4v2n1k) version, the only way to install AppBlips on Windows, is signed by Microsoft.

## What this means for you

- **Windows, Microsoft Store:** signed, so Windows installs it without warnings, and the Store keeps it up to date. This is the only supported way to install AppBlips on Windows.
- **Linux:** the AppImage and `.deb` files aren't code-signed, but Linux doesn't warn about that the way Windows does.

## How releases are built

Every Linux release on GitHub is built automatically from the [`TechMitten/app-blips`](https://github.com/TechMitten/app-blips) repository by the [Desktop workflow](https://github.com/TechMitten/app-blips/blob/master/.github/workflows/desktop.yml) on GitHub's servers. Nobody builds those files by hand. The project owner, [@TechMitten](https://github.com/TechMitten), checks each release before publishing it on the [Releases page](https://github.com/TechMitten/app-blips/releases).

The Microsoft Store package is built by the project owner from the same source code and uploaded to Microsoft. Microsoft reviews it, signs it, and delivers it and its updates through the Store.

## Check that your download is genuine

This applies to the Linux downloads from GitHub. The Store checks its own package's signature for you.

Each release includes a `SHA256SUMS.txt` file that lists a fingerprint for every download. If your file's fingerprint matches the one in the list, the file is exactly what the workflow built.

1. Open a terminal in the folder that holds your download.
2. Type `sha256sum <file name>` and press **Enter**.
3. Compare the long code with the line for that file in `SHA256SUMS.txt`.

## Privacy

AppBlips sends your prompts and projects only to the AI provider you set up in **Settings → API**. It also connects to a few other services, for fonts, code libraries and updates. See [What does AppBlips connect to?](/reference/faq) in the FAQ for the full list.
