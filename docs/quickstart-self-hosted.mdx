<Tip>
  On Windows or Linux, the [desktop app](/quickstart-desktop) is the easier way to run your own copy: download it, install it, and add your API key in the app.
</Tip>

Running from source is for macOS users (there is no installer yet), people who want to change AppBlips itself, and anyone who prefers a terminal. You get the same AppBlips as the desktop app, running in your browser: no account, no cloud sync, and your projects stay in your browser. It's designed for a single local user, so there's no sign-in flow.

## Prerequisites

<Note>
  Self-hosting AppBlips requires **Node.js 20.19 or newer** (or **Node.js 22.12 or newer**). npm is included with Node.js, so no separate install is needed. Download Node.js at [nodejs.org](https://nodejs.org/).
</Note>

## Set up with Node.js

<Steps>
  <Step title="Clone the repository">
    Download the AppBlips source code and move into the project folder:

    ```bash
    git clone https://github.com/techmitten/app-blips.git && cd app-blips
    ```
  </Step>
  <Step title="Install dependencies">
    ```bash
    npm install
    ```
  </Step>
  <Step title="Copy the config file">
    Create your local configuration file from the provided example:

    ```bash
    cp .env.example .env
    ```
  </Step>
  <Step title="Add your API key and model">
    Open `.env` in any text editor and fill in **two lines**: the API key for one provider, and the model. The file lists OpenAI, OpenRouter, DeepSeek, Z.ai, and Z.ai Coding Plan. The provider whose key is filled in becomes active, so leave the others blank.

    ```bash
    APPBLIPS_OPENAI_API_KEY=your-api-key
    OPENAI_LLM_MODEL=gpt-5.1
    ```

    Write the model name exactly as your provider does. Apps you build with AI turned on use this same provider and model, so there is nothing else to set up.

    <Tip>
      You can also skip this step and choose a provider, model, and key in the app under **Settings → AI**. See [Your own AI provider](/reference/settings#your-own-ai-provider).
    </Tip>
  </Step>
  <Step title="Start AppBlips">
    ```bash
    npm run dev
    ```

    AppBlips prints which AI provider it found and anything that is still missing, followed by the local address.
  </Step>
  <Step title="Open AppBlips in your browser">
    Navigate to [http://localhost:5175](http://localhost:5175). Type a prompt and start building.
  </Step>
</Steps>

Prefer containers? [Docker](/self-hosting/docker) runs the same thing from a single command.

<Warning>
  A self-hosted copy has **no sign-in**. The `/api/chat` and `/api/app-ai/chat` endpoints accept every request as the same local user and spend your API key. Keep AppBlips on your own computer. If other devices on your network can reach it, put your own access control in front of it.
</Warning>

## Updating

AppBlips tells you when a new version is out (you can turn this off in **Settings → Workspace → Check for updates**). To update, run this in the project folder, then restart AppBlips:

```bash
git pull
npm install
```

With Docker, run `docker compose up --build` after `git pull`.

## Supported AI Providers

| Provider | `.env` key | Example model |
|---|---|---|
| OpenAI | `APPBLIPS_OPENAI_API_KEY` | `gpt-5.1` |
| OpenRouter (Claude, Gemini, and most other models) | `OPENAI_API_KEY` | `anthropic/claude-sonnet-5` |
| DeepSeek | `APPBLIPS_DEEPSEEK_API_KEY` | `deepseek-chat` |
| Z.ai | `APPBLIPS_ZAI_API_KEY` | `glm-5.3-flash` |
| Z.ai Coding Plan | `APPBLIPS_ZAI_CODING_API_KEY` | `glm-5.3` |

Any other OpenAI-chat-completions-compatible service works too, including local models through Ollama, vLLM, or LM Studio. Fill in `OPENAI_BASE_URL` (for example `http://localhost:11434/v1`), `OPENAI_API_KEY` (Ollama needs none, so put any text), and `OPENAI_LLM_MODEL`. See [Configuration](/self-hosting/configuration#other-openai-compatible-services).

Your provider key is used only by the AppBlips server and is never sent to the browser.
