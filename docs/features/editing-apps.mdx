Once AppBlips has built your project, you have two ways to refine it: type a plain-English follow-up prompt to describe the change you want, or (if you are in the Website Studio) switch into the visual editor and click directly on the element you want to modify. Both approaches create a new version in your history, so you can always undo if a change misses the mark.

## Editing with Prompts

After your app is generated, the prompt input stays active and ready for follow-up instructions. Describe the change you want in plain English — AppBlips reads the current version of your app and applies your requested change directly.

A few examples of effective editing prompts:

```
Change the background to dark blue and the text to white.
```

```
Add a search bar at the top that filters the list as you type.
```

```
Replace the dropdown with a set of radio buttons.
```

```
Move the submit button to the bottom-right and make it green.
```

Each follow-up creates a new version in your history, so you can chain as many edits as you like and step back if something doesn't work.

## Visual Element Editor (Website Studio)

When working in the **Website Studio**, the visual element editor lets you point and click on any element in the live preview to select it and describe a change. This is especially useful when you can see exactly what you want to fix but aren't sure how to describe it in words.

To activate the visual editor, click the **Click-to-edit** key (the pointer icon) in the preview toolbar. The preview switches into selection mode: hover over any element and it highlights to show you what would be selected. Click the element you want to change. An editor bar appears below the preview with the options for that kind of element.

## Edit text directly

Click any text in the preview, such as a heading, paragraph or button label, and type straight into it. A formatting bar appears while you type:

- **Font**, and the font size (**Smaller**, **Larger**, or type a size in pixels)
- **Text style** (such as bold and italic) and **Alignment**
- **Text color**, from a list of colours or a custom colour
- Its own **Undo** and **Redo** for your typing

Press Enter to start a new line. Click **Done**, click somewhere else in the preview, or press Ctrl+Enter (⌘+Enter on a Mac) to save the change as a new version. Click **Cancel** (or press Escape) to throw it away. No AI is involved, so the change is instant.

## Change an image

Click an image to change it in the editor bar:

- **Image URL:** paste the web address of another picture.
- **Upload:** replace it with an image from your computer.
- **Alt text:** a short description of the picture for people who use screen readers. It also shows if the image can't load.

## Selecting parent elements

Sometimes you want to edit a container, section background or wrapper rather than the content inside it. After clicking an element, click the **Select parent** key in the editor bar (an arrow pointing up to a line; its tooltip says "Select the parent"). This is useful when you want to change a section's background, a card's fill or a page region's layout.

Keep clicking it to move further out until you've highlighted the element you actually want to edit.

## Arranging Elements

The editor bar has keys to rearrange whatever you have selected. Each one is saved straight away as a new version, with no AI involved:

| Action | Key in the bar | Shortcut |
| --- | --- | --- |
| Move up / down among its neighbours | Arrow keys | Alt+↑ / Alt+↓ (⌥ on Mac) |
| Duplicate it right below itself | Duplicate | Ctrl+D (⌘D on Mac) |
| Delete it | Delete | Delete or Backspace |

### Drag to move

You can also drag text, images, buttons or whole sections to a new spot. Next to the click-to-edit key is a **Drag mode** key (the move icon). Turn it on (this also turns click-to-edit on), then press on an element in the preview and drag it: a copy of it follows your pointer (large elements shrink so you can still see the page), and a line shows where it will land, before or after the element under your pointer, anywhere on the page. Release to move it, or press Escape to cancel. Hold the pointer near the top or bottom edge of the preview to scroll while you drag.

In drag mode, hovering outlines what a drag would move, and a click selects an element without editing its text. To move a container such as a card or a section, click it (use **Select parent** if needed), then drag from anywhere inside it. Turn drag mode off to edit text in place again. Words inside a paragraph or heading move with their paragraph. Elements stay in the normal page flow, so the layout still adapts to every screen size. List items can only be moved among list items, and table cells among table cells.

If the dragged element or the spot where you drop it can't be found exactly in the page source (for example, because a script added it), nothing moves. The element is selected so you can describe the move to AI instead.

Ctrl+Z (⌘Z on Mac) undoes the last change, even while you're working in the preview. When you move or delete a whole section, its section marker goes with it. A duplicate gets no `id` attributes, so links to the original section still land on the original.

## Links, Buttons and Backgrounds

- **Links:** type a web address, or pick one of your site's pages or a `#section` from the suggestions. The arrow key next to the field makes the link open in a new tab.
- **Fill:** a colour for sections, buttons and links. If the element has a gradient, a solid fill replaces it.
- **Wallpaper:** upload an image as a section's background, whether or not the section had one before.

## Asking AI About One Element

When a change is more than a quick tweak, click **Ask AI** in the editor bar and describe it. **Apply with AI** makes the change right away. **Add to chat** puts the request in the chat box so you can add to it before sending. Either way, the request includes the element's exact source code and the page section it's in, so the AI edits that element and not a look-alike somewhere else.

If a direct edit can't be matched to the page's source, for example because a script creates that part of the page, the bar tells you why and switches to Ask AI.

## Undo/Redo History

Every edit — whether made through a prompt or the visual editor — saves a version to your history automatically. Use the **Previous version** and **Next version** arrows in the preview toolbar to step back and forward, or press Ctrl+Z to undo and Ctrl+Y or Ctrl+Shift+Z to redo (⌘Z and ⌘⇧Z on Mac). You can move between versions freely at any point without losing your work. To jump straight to an older version, open the [history drawer](/features/live-preview#history-drawer).

<Tip>
  Combine both editing modes for the best results. Use the visual editor to pinpoint a specific element you want to change, then use a follow-up prompt to describe complex behavior changes — like adding new interactivity or restructuring a section. Switching between the two gives you precision on individual elements and flexibility for bigger changes.
</Tip>
