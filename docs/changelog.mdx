Each entry lists what changed in that version of AppBlips, newest first. To get the latest version, see [Install the desktop app](/quickstart-desktop) or [Run from source](/quickstart-source). Downloads for every release are on [GitHub Releases](https://github.com/TechMitten/app-blips/releases).

<Update label="0.1.20" description="October 27, 2026" tags={["New", "Improved", "Look and feel"]}>
  ## New

  - **Choose apt updates when you install (Debian and Ubuntu).** The `.deb` now asks "Get AppBlips updates through apt?" during install. Say yes and new versions arrive with `sudo apt upgrade` and in your software center. The default is no. See [Install the desktop app](/quickstart-desktop).
  - **Fit an image to its replacement.** After you upload a new picture in click-to-edit, tick **Fit size to image** to keep the width and match the new picture's proportions.
  - **Build blueprint.** While a build runs, you see a wireframe of your page assembling step by step, with the live code one click away.

  ## Improved

  - **Alt text** opens in a small window with an Apply button, and the element id chip is gone from the editor bar.
  - **Update check** now asks GitHub every hour instead of every 12 hours.

  ## Look and feel

  - The splash screen now plays a short silent animated video that fades in and out, with updated artwork.
</Update>

<Update label="0.1.19" description="October 27, 2026" tags={["New", "Improved", "Look and feel"]}>
  ## New

  - **Update with apt on Debian and Ubuntu.** Add the AppBlips package source once, and new versions arrive with `sudo apt update && sudo apt upgrade` and in your software center. See [Install the desktop app](/quickstart-desktop).

  ## Improved

  - **Click-to-edit with part of the text highlighted:** Bold, color and other toolbar formatting now apply to just the highlighted words instead of the whole line or heading.
  - **Click-to-edit saves reliably next to inline tags.** Headings like "dark, played", where one word is styled separately, no longer fail to save with "could not be found in the page source".
  - **Update notice:** it now also appears during first-run setup, and on `.deb` installs without the package source its button downloads the installer directly.

  ## Look and feel

  - A slimmer text cursor while editing, so it no longer towers over large hero text.
  - The update notice stands out against your theme, and the first-run setup screens have tidier layout and styling.
</Update>

<Update label="0.1.18" description="October 27, 2026" tags={["New", "Improved", "Look and feel"]}>
  ## New

  - **SEO connector.** Answer a few friendly questions and the AI adds search-engine optimization to your site, plus a sitemap and robots file when you export or publish. No account needed.
  - **My images is now a connector (beta).** Turn it on in **Settings → Connectors → My images**. You can also hide individual images from the AI with the eye button; pages that already use them keep working.
  - **"Looks fine but doesn't work."** After a build, the review prompt has a second choice that clicks through every control to find things that look right but don't work.
  - **Credits left in the Build header.** If you use AppBlips AI Credits, your remaining credits show at the top of the Build pane. Click them to open **Settings → Account & Usage** (formerly Account), which now has a usage bar that turns amber at 75% and red at 90%.

  ## Improved

  - Settings asks before replacing your AppBlips AI Credits with your own API key.
  - When the credits server turns a request down (for example, no credits left), you now see its real reason instead of "You're sending requests too quickly".
  - Onboarding waits on the "Connect your AI Credits" screen after you open the pricing page, so coming back from checkout lands on the email box.
  - Factory Reset also signs you out of AppBlips AI Credits, and the plan descriptions are clearer.
  - The live code peek on the building screen no longer goes blank mid-edit.
  - Account & Usage no longer flashes the signed-out view while loading.
  - The token counter has been removed from the chat. Check usage in **Settings → Account & Usage**, or on your provider's usage page.
  - The refund rules now say that AI results aren't refundable, and what is.

  ## Look and feel

  - Streamed code in chat is readable in the light theme.
  - The studio picker fits in the window without scrolling, and the Showcase stays full height on short windows.
  - Neutral (non-red) accents in the SEO window, a wider Settings sidebar, a larger splash image on phones, and a tidier mobile header.
</Update>

<Update label="0.1.15" description="October 24, 2026" tags={["New", "Improved", "Look and feel"]}>
  ## New

  - **AppBlips AI Credits.** Build without an API key. Start a 3-day free trial (100 credits; requires a valid payment method and converts to the $10/month Starter Plan for 1,000 credits a month unless cancelled) or pick a monthly plan. Connect with a sign-in code emailed to you, entered in six boxes. Your own saved API provider always takes priority if configured.
  - **Account tab in Settings** with a support email and a **Cancel subscription** link.
  - **My images gallery (beta).** Upload your own photos and logos per project, ask the AI to place them by name, and they're bundled when you export or publish.
  - **Showcase.** Browse real AppBlips websites and games from the studio picker, even offline, and submit your own after publishing.
  - **Site icons.** Choose a favicon in the Publish window before publishing to Surge.
  - **Link confirmation.** AppBlips asks before opening an external website.

  ## Improved

  - Onboarding asks whether you want to bring your own API key or use AI Credits.
  - Websites and imported sites can use **Full size** preview.
  - Electron updated to 44.9.1 for Chromium security fixes.
  - The Docker guide now says to install Docker Compose v2.

  ## Look and feel

  - The light theme has higher contrast, with firmer borders, darker secondary text and solid chat bubbles, and a navy accent while building.
  - The "Your turn" box is gone from onboarding.
</Update>

<Update label="0.1.14" description="October 23, 2026" tags={["New", "Improved", "Look and feel"]}>
  ## New

  - **Full size preview.** A **Full size** button next to the device sizes drops the window frame and shows your page at its real size, filling the whole preview area. It works in every studio.
  - **About tab in Settings.** **Settings → About** shows the AppBlips version you're running (desktop app or browser version), links to the website and source code, and a **Report a bug** link that opens a new issue on GitHub.

  ## Improved

  - **Preview toolbar:** Rotate, Full size and a new **Reload** button are always in the same place, so the toolbar no longer shifts when you switch devices. Buttons that don't apply to the current view are greyed out.
  - **Phone and tablet previews:** no desktop-style browser bar, just like a real phone or tablet. While the AI is testing your page, its status and **Stop** button appear in the preview toolbar instead.
  - **Images in games:** the Game Studio can use Pollinations to make title art, backgrounds and sprites.
  - **Questions about connectors:** in Ask mode, the AI knows which services you've connected, instead of wrongly saying it can't use them.
  - **Guided tour:** updated for Publish, Full size, Reload, importing a site and **Settings → Connectors**. Imported sites get their own steps.

  ## Look and feel

  - In the dark theme, the live code card on the building screen has a soft white border instead of a red one.
  - The guided tour's cards stand out clearly against the dark theme.
</Update>

<Update label="0.1.13" description="October 23, 2026" tags={["New", "Improved", "Look and feel", "For developers"]}>
  ## New

  - **Pollinations connector for AI images and AI features.** Connect your [Pollinations](https://github.com/pollinations/pollinations) account in **Settings → Connectors → Pollinations**, then ask the AI for:
    - **Generated images:** custom pictures instead of stock photos. When you publish or export, the images are copied into your site, so they stay online with it.
    - **AI features:** chatbots, writing helpers, image generators and more, inside the websites and apps you build. You choose who pays when visitors use them: **Visitors use their own Pollen** (the default) or **My key pays**.

    The AI only uses Pollinations when you ask for images or AI features. Your sign-in stays inside AppBlips and is never written into your projects. Using Pollinations through AppBlips costs 25% more than using it directly, and the extra supports AppBlips. See [Connectors](/features/connectors).
  - **Token usage in the chat.** Each reply shows how many tokens it used, and a live counter counts up while the AI works. Both are marked "(estimate)", because AI providers count tokens differently.

  ## Improved

  - **Surge in Connectors:** a Surge tile in **Settings → Connectors** lets you sign in, create an account or sign out without publishing anything.
  - **Sharing a published site:** the share buttons in the **Publish** window show each service's logo.
  - **Onboarding:** setup is split into three short steps: your name, your chat avatar, then your AI provider.
  - **Code tab:** shown by default.
  - **Chat bubbles:** the rewind button sits inside your message, next to copy. The copy button is easier to see in the dark theme.
  - **Renamed button:** "Browser view" is now **Preview**.

  ## Look and feel

  - New wave-and-blip app icon, shown next to the AppBlips name throughout the app.
  - Refreshed preview background in dark mode.
  - The building screen is easier to read in the light theme.
  - Connector icons no longer sit on a coloured square.

  ## For developers

  - `npm run dev` only answers on your own computer (localhost). Use `npm run dev -- --host` to open it to your network.
</Update>

<Update label="0.1.11" description="October 22, 2026" tags={["New", "Improved", "Look and feel"]}>

Sign in to (or create) your own Surge account in the **Publish** window. A project that's already online shows **Update site** and **Unpublish**. See [Publishing](/features/publishing).

  - **Prompts to try:** every connector page has ready-made requests with **Copy** buttons.
  - **Request a connector:** a form at the end of **Settings → Connectors** sends your suggestion to the AppBlips team.

  ## Improved

  - **Starter ideas:** each studio has dozens of ideas, shuffled every launch. Browse them with the arrow keys or by swiping.
  - **Copy buttons** in every chat bubble.
  - **Onboarding** asks for your name and a chat avatar.
  - **Factory reset** now replays first-run setup.
  - **Theme toggle** (sun and moon) on the studio picker.

  ## Look and feel

  - Restyled preview toolbar, with readable buttons in the light theme.
  - Connector cards show each service's logo and link to its website.
  - Brand-red accents on the studio picker and the selected preview device.
</Update>

<Update label="0.1.10" description="October 22, 2026" tags={["New", "Improved", "Look and feel", "Security"]}>
  ## New

  - **Connectors.** A new **Settings → Connectors** tab lists services the AI can wire into your projects, starting with Web3Forms: with it turned on, forms in your sites send their entries to you. Each connector has a **How it works** dialog.
  - **Licenses** tab in Settings, listing the open source software AppBlips includes.
  - **Setup steps after a build.** When a project needs something only you can supply, such as an API key, the AI's last message ends with numbered steps.

  ## Improved

  - **Code Review** asks **Fix problems** or **Not now** before fixing anything. Its screenshots cover whole pages, and every problem it reports must point to a screenshot that shows it.
  - Settings asks you to confirm before clearing your saved AI provider.
  - The first-visit tour invitation goes away on its own.
  - The project name is treated as a name, not as instructions for the AI.
  - Fixed: the Linux `.deb` package showed a generic icon in the launcher.
  - A security issue was fixed.

  ## Look and feel

  - Light themes for the studio picker, the first-build screen and the building phone.
  - New AppBlips wordmark on the studio picker, setup and empty preview screens.
  - The setup screen has a monochrome look and works properly on phones.
  - Interface text can no longer be highlighted by accident. Chat messages and fields can still be selected and copied.
</Update>

<Update label="0.1.9" description="October 19, 2026" tags={["Improved"]}>
  ## Improved

  - **Windows:** AppBlips for Windows now comes only from the Microsoft Store, which is signed and updates itself. GitHub releases no longer include a Windows installer.
  - **Projects folder:** new installs save projects in AppData instead of Documents. Existing installs keep their folder.
  - **Code Review** is marked beta and is off by default for new installs.
  - The preview's address bar shows your project name.
  - A Discord link was added to the studio picker.
  - Fixed: the preview lost its scroll bar after applying a click-to-edit change.
  - Docker: the voice input model is no longer downloaded again on every rebuild.
</Update>
