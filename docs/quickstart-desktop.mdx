The desktop app is the easiest way to run your own copy of AppBlips. It installs like any other program: no account, no terminal, no configuration files. You bring an API key from an AI provider, and your projects are saved as folders on your computer.

<Note>
  On macOS there is no installer yet. You can [run AppBlips from source](/quickstart-source) instead, in your browser. To run it in a container, see [Docker](/self-hosting/docker).
</Note>

## Install

<Tabs>
  <Tab title="Windows">
    1. Open [AppBlips in the Microsoft Store](https://apps.microsoft.com/detail/9nk9ss4v2n1k).
    2. Click **Get** (or **Install**).
    3. When it finishes, open AppBlips from the Start menu.

    The Store version is signed by Microsoft, so Windows doesn't block it, and the Store keeps it up to date. This is the only supported way to install AppBlips on Windows.
  </Tab>
  <Tab title="Linux">
    Download either file from the [Releases page](https://github.com/TechMitten/app-blips/releases):

    - **AppImage** (any distribution): make it executable with `chmod +x AppBlips-*.AppImage`, then run it.
    - **.deb** (Debian, Ubuntu and derivatives): install it with `sudo apt install ./AppBlips-*.deb`.
  </Tab>
</Tabs>

## Tell AppBlips about you

The first time you open AppBlips, a screen titled **First, tell us about you** appears:

1. **Your name:** type your name or a nickname.
2. **Your avatar:** click a picture. It appears next to your messages in the chat.
3. **Save projects in:** this shows the folder where AppBlips keeps your projects. To use a different one, click **Change** and pick a folder. You can also change it later in **Settings → Data**.
4. Click **Continue**.

## Set up your AI provider

An API key is a password-like code from your AI provider. It lets AppBlips use the AI on your account, and the provider bills you for what you use.

Next, a setup screen titled **Choose the AI that builds with you** appears:

1. **Provider:** pick Anthropic (the default), OpenAI, Gemini, DeepSeek, LM Studio, Ollama or OpenRouter.
2. **API key:** paste your key. Create one at [Anthropic](https://platform.claude.com/settings/keys), [OpenAI](https://platform.openai.com/api-keys), [Google AI Studio](https://aistudio.google.com/apikey), [DeepSeek](https://platform.deepseek.com/api_keys), or [OpenRouter](https://openrouter.ai/settings/keys). LM Studio and Ollama don't need a key: start your local server instead.
3. **Model:** choose one from the list. The list comes from your provider, so add your API key first; if you open the list without one, AppBlips reminds you.
4. Click **Start building**. If something is missing, the screen tells you what. To go back to your name and avatar, click **Back**.

To look around first, click **Skip for now** on either screen. You can set up the AI later.

To change any of this later, open **Settings → API**. There you can click **Refresh models** to reload the list, or type an exact model ID if the list can't load. For OpenAI, choose a model that supports tool calling through Chat Completions. Click **Test connection**, then **Save**. To see the setup screens again (for example, to change your name or avatar), open **Settings → Workspace** and click **Replay**.

Your key is encrypted with your system keychain (Windows Data Protection, or GNOME Keyring/KWallet on Linux) and is only used by the app's background process. The app's own web page, your projects and the apps you build never see it.

<Note>
  On Linux without a keyring, the app warns that the key is stored with weak encryption. Install GNOME Keyring or KWallet to protect it properly.
</Note>

## Build your first app

After setup, AppBlips asks what you want to make:

1. Click a studio: **Mobile & Web App**, **Responsive Website** or **Browser Game**. To start from a template instead, click **Quick Start & Library**.
2. Type what you want in plain English, for example "a habit tracker with checkboxes and a progress bar".
3. Press Enter. Your app appears in the preview when it's built.

See [Building Apps](/features/building-apps) for tips on writing prompts.

## Where your projects are saved

Each app you build is a folder in AppBlips' own data folder, out of the way so it isn't deleted by accident:

- **Windows:** `C:\Users\<your name>\AppData\Roaming\AppBlips\Projects`
- **Linux:** `~/.config/AppBlips/Projects`

`AppData` is a hidden folder. The easiest way to get there is **Settings → Data → Projects folder → Open**. If you used AppBlips before version 0.1.9 and have projects in `Documents/AppBlips/Projects`, AppBlips keeps using that folder instead.

<Warning>
  If you installed AppBlips from the Microsoft Store, uninstalling it or clicking **Reset** in Windows Settings → Apps deletes this folder and every project in it. Updates don't. Before uninstalling, use **Export all apps** (below) or pick a folder of your own with **Change…**.
</Warning>

Inside each app's folder:

| File | What it is |
| --- | --- |
| `project.json` | The whole project: every version and the chat history |
| `app-data.json` | What the app itself saved with `localStorage` while you used its preview |
| `site/` | The current version's pages as plain `.html` files, rewritten on every change |
| `blobs/` | Imported sites only: the project's files, stored once each so versions stay small |

The `site/` folder is a convenience copy: open or share those files freely, but edits there are not read back into AppBlips. Renaming an app renames its folder, and deleting one moves the folder to your system trash.

To use a different folder, open **Settings → Data → Projects folder → Change…**. You can move your existing projects there at the same time.

## Back up or move your projects

To back up your apps, or move them to another computer:

1. Open **Settings → Data** and click **Export**. This downloads one backup file with every app, its versions and its saved app data.
2. On the other computer (or after reinstalling), open **Settings → Data**, click **Import…** and choose that file.

An app you already have is only replaced if the backup's copy is newer. Imported sites aren't included in the backup: export each one as a `.zip` instead (see [Import a React + Vite site](/features/importing-sites#export-the-project)).

## Updates

AppBlips checks for new versions when it starts, and again every hour while it's open.

- **Microsoft Store:** the Store updates AppBlips for you. When a new version is out, AppBlips also tells you and links to its Store page, so you can update straight away. A new version can take a day or two to appear in the Store.
- **AppImage:** a new version downloads in the background. When it's ready, AppBlips offers **Restart to update**. If you choose **Later**, it installs the next time you close AppBlips.
- **.deb:** AppBlips tells you a new version is out and links to the download. Install it the same way as the first time (`sudo apt install ./AppBlips-*.deb`); your projects and settings stay as they are.

To turn the check off, go to **Settings → Workspace → Check for updates**. The check asks GitHub, where releases are published, so GitHub sees your IP address.
