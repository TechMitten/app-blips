<Note>

</Note>

Docker is an alternative to `npm run dev` for running AppBlips on your own computer. A single `docker compose up --build` command builds the client, packages it with a small Node server, and starts everything together — no Node.js installation needed on your machine. The server handles the builder API and serves the built client directly.

## Prerequisites

Before you begin, make sure you have:

- [Docker](https://docs.docker.com/get-docker/) and [Docker Compose](https://docs.docker.com/compose/install/) installed and running
- A `.env` file with `OPENAI_API_KEY` and `OPENAI_LLM_MODEL` filled in — see [Configuration](/self-hosting/configuration) for the full reference

## Starting AppBlips

<Steps>
  <Step title="Clone the repository">
    Download the AppBlips source and move into the project directory:

    ```bash
    git clone https://github.com/techmitten/app-blips.git
    cd app-blips
    ```
  </Step>

  <Step title="Create your .env file">
    Copy the example configuration file and open it in your editor:

    ```bash
    cp .env.example .env
    ```

    Fill in your DeepSeek API key and the model:

    ```bash
    OPENAI_API_KEY=your-deepseek-api-key
    OPENAI_LLM_MODEL=deepseek-v4-pro
    ```
  </Step>

  <Step title="Build and start the container">
    Run the following command from the project root:

    ```bash
    docker compose up --build
    ```

    Docker will build the client bundle, assemble the runtime image, and start the server. The first build takes a minute or two as it installs dependencies and compiles the front end. Subsequent builds are faster thanks to Docker's layer cache.
  </Step>

  <Step title="Open AppBlips in your browser">
    Once you see `AppBlips listening on port 3000` in the terminal output, navigate to:

    ```
    http://localhost:3000
    ```

    You're ready to start building apps.
  </Step>
</Steps>

## Ports

AppBlips listens on port **3000** inside the container. `docker-compose.yml` publishes it as `127.0.0.1:3000`, so only your own computer can reach it. To use a different host port, change the first number and keep the `127.0.0.1:` prefix:

```yaml
ports:
  - "127.0.0.1:8080:3000"   # http://localhost:8080 → container port 3000
```

<Warning>
  Removing the `127.0.0.1:` prefix makes AppBlips reachable from other devices on your network. It has no sign-in, so anyone who can reach it can spend your API key.
</Warning>

## Applying Config Changes

Configuration is read when the server starts. After changing `.env`, run `docker compose up` again: Compose sees the new values and recreates the container. A plain `docker compose restart` keeps the old values.

## Stopping and Updating

To stop AppBlips, press `Ctrl+C` in the terminal running `docker compose up`, or run the following from the project directory:

```bash
docker compose down
```

To update to a newer version of AppBlips, pull the latest code and rebuild:

```bash
git pull
docker compose up --build
```

<Note>
  The AppBlips server is a plain Node.js process that relies only on built-in Node modules — no `node_modules` directory is included in the runtime image. This keeps the final image small and eliminates a class of supply-chain risk from runtime dependencies.
</Note>
