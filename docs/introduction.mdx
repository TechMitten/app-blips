AppBlips is a text-to-app generator built for everyone with an idea, whether or not you write code. You describe what you want in plain English — "a habit tracker with checkboxes and a progress bar" or "a multi-page portfolio website" — and AppBlips builds it as a real, interactive app you can use right away. There is no code to write, no project to set up, and no build step to run. Whether you are a designer, a student, a small-business owner, a developer sketching a prototype, or simply someone who wants to try an idea quickly, AppBlips gives you a working app or website in seconds, with the code there to read, export, and change whenever you want.

## What You Can Build

AppBlips opens on a choice of studios:

- **Mobile & Web App:** interactive tools, dashboards and utilities that work on any device.
- **Responsive Website:** multi-page sites with navigation that look good on every screen.
- **Browser Game:** 2D and 3D games with keyboard and touch controls.
- **Quick Start & Library:** reopen something you made before, or start from a ready-made template.
- **Import a site:** keep editing a React + Vite project someone built for you (see [Import a React + Vite site](/features/importing-sites)).

## How It Works

<Steps>
  <Step title="Type a prompt describing your app">
    Write a plain-English description of the app you want. Be as specific or as brief as you like — AppBlips works with both. You can also attach a screenshot or reference image for AppBlips to build from.
  </Step>
  <Step title="AppBlips sends it to your AI provider">
    Your prompt goes to the AI provider you chose, such as Anthropic or OpenAI. While the AI works, you can watch the code being written in a small peek window.
  </Step>
  <Step title="Your app appears in a live preview">
    The moment the build finishes, your app runs in a safe, sandboxed preview right next to the prompt. You can use it immediately, with no separate step.
  </Step>
  <Step title="Refine with follow-up prompts or export">
    Type another prompt to tweak any detail. Every change is saved as a version you can undo. When you are happy, export your project as a single HTML file, a ZIP of pages, or a React project.
  </Step>
</Steps>

## Running AppBlips

AppBlips runs on your own computer, with your own AI provider API key. There is no account and no cloud sync. Pick the way that suits you:

<CardGroup cols={3}>
  <Card title="Desktop app" icon="download" href="/quickstart-desktop">
    The easiest way. Install it on Windows or Linux; projects are saved as folders on your computer.
  </Card>
  <Card title="Run from source" icon="code" href="/quickstart-source">
    Start it with Node.js and use it in your browser, or build the desktop app yourself. Works on macOS too.
  </Card>
  <Card title="Docker" icon="docker" href="/self-hosting/docker">
    One command starts it in a container. Use it in your browser, with nothing else to install.
  </Card>
</CardGroup>

There is no macOS installer yet: on a Mac, run from source or use Docker.
